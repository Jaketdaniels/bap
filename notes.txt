## 2026-08-19 — planning docs

- Scope decided: plan all 5 phases; implement Phase 1 only this session. Git init approved.
- Stack confirmed against current upstream: `deno_core 0.410` + `deno_ops 0.286` + `serde_v8 0.319`.
  Verified from docs.rs/examples: `extension!` uses `config = {...}` + `state = |state, config| state.put(config.field)`,

- Benchmark honesty: Phase 6 SSR numbers are synthetic-route comparisons; real Next.js-on-Bap is out of scope.
