Bap runtime

Run JavaScript and TypeScript with a small Rust core.

Bap combines V8, a focused async runtime, source-mapped TypeScript loading, and a numeric core designed for exact boundaries.

Run your first script Read the README

Quick start

Build the workspace, then run either JavaScript or TypeScript.

cargo build --workspace
target/debug/bap run examples/hello.js
target/debug/bap run examples/hello.ts

REPL and metrics

Use the REPL for small experiments. Keep script output clean with JSON metrics on stderr.

target/debug/bap repl
target/debug/bap --metrics json run examples/hello.ts

Runtime APIs

The lowercase bap global provides file, network, and fetch helpers. Timers use the same event loop.

const response = await bap.fetch("https://example.com");
console.log(response.status, await response.text());

await bap.writeFile("/tmp/output.txt", "hello from bap\n");

TypeScript loading

Bap strips TypeScript types, keeps source maps, and caches compiled modules. A JavaScript entry can import a TypeScript dependency.

Numeric core

bap_math currently lives on the Rust side. It provides outward-rounded intervals, checked integers, and Fixed<18,4> decimal arithmetic.

Proof tool

The standalone TypeScript proof tool checks a bounded unit-aware subset and writes JSON evidence. Runtime integration is the next slice.

npm --prefix tools/ts-proof ci
npm --prefix tools/ts-proof test

Project status

This is a working proof of concept. Node compatibility, native add-ons, JavaScript numeric bindings, proof consumption, and real application latency tests remain on the roadmap.
